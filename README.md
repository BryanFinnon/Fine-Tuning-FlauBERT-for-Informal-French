# Fine-Tuning-FlauBERT-for-Informal-French
Fine-tuned FlauBERT for informal French using a domain-adaptive strategy (DAFT) to handle noisy text. Built and processed a 110K+ dataset with advanced preprocessing. Improved correlation from 0.3 to 0.8 (+160%). Tech: Python, Hugging Face Transformers, Scikit-learn.
